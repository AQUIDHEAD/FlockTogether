Making a reusable lilly-pad component

### Lilly-pad

Create a new `components` folder in `src/`. Inside the new `components` folder create a file named `Lilly-pad.tsx` and whithin it write the code for a resuable lilly-pad components that will be reused as a visual element in other components.

Requrements:

- Create `components` folder in `src/`
- Create `Lilly-pad.tsx`
- Make lilly-pad in the shape of a pizza with a slice taken out
- Follow the guidelies in `context/design.md`
